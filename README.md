# Aline Stephanie Fernandes da Silva

## Portfólio Profissional

Portfólio profissional desenvolvido para apresentar minha formação, experiências, conhecimentos e interesses nas áreas de Agronomia, agronegócio, tecnologia e inovação.

## Sobre o projeto

Este portfólio reúne informações sobre minha trajetória acadêmica e profissional, além de conhecimentos relacionados ao setor agrícola e ao uso de tecnologias aplicadas ao agronegócio.

O projeto possui uma área administrativa integrada ao Supabase, permitindo atualizar informações do portfólio de forma online.

## Áreas de interesse

- Agronomia
- Agronegócio
- Agricultura de precisão
- Classificação de grãos
- Tecnologia aplicada à agricultura
- Inovação no setor agrícola
- Sustentabilidade
- Gestão e produção agrícola

## Tecnologias utilizadas

- CSS
- JavaScript
- Supabase
